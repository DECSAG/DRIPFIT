# DRIPFIT - Premium T-Shirt Store

Welcome to DRIPFIT, your ultimate destination for premium, stylish t-shirts that express your personality and individuality.

## 🎨 Features

- **Modern Responsive Design**: Beautiful layout that works on all devices
- **Product Showcase**: Display your t-shirt collection with product cards
- **Shopping Experience**: Add to cart functionality with live cart updates
- **About Section**: Tell your brand story
- **Contact Form**: Easy way for customers to reach you
- **Smooth Animations**: Engaging user experience with smooth transitions

## 🚀 Getting Started

1. Clone the repository or download the files
2. Open `index.html` in your web browser
3. Customize the content, colors, and products to match your brand

## 🛠️ How to Customize

### Change Colors
Edit the gradient colors in `styles.css`. Look for sections like:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Add New Products
Duplicate a product card in `index.html` and update:
- Product image (background gradient)
- Product name
- Price
- Description

### Modify Navigation
Edit the navigation links in the `<nav>` section to add or remove menu items.
